# Frontend implementation plan

The active plan is [WORKBENCH_IMPLEMENTATION_PLAN.md](WORKBENCH_IMPLEMENTATION_PLAN.md).
The October 2026 direction is dark-first, governed by DESIGN_RULES.md and DESIGN_SYSTEM.md.
Older plans describing a paper-light desk or a 248px persistent sidebar are historical and
must not be used as implementation requirements.

The existing App Router, horizontal desktop route index, mobile bottom navigation/drawer,
page primitives and domain components remain the foundation. API contracts, providers,
database/RLS, explicit AI actions, task acceptance and copy-only drafts stay unchanged.

Acceptance requires the full quality gate, real browser screenshots at all seven release widths,
critical demo journeys, evidence links, visible uncertainty, mobile/keyboard focus and reduced motion.
Hosted Auth/provider verification and physical device/screen-reader acceptance are separate gates.
