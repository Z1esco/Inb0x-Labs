# Contributing

Use `main` for stable releases, `develop` for integration, `setup/foundation` for the initial
foundation, and `feat/*`, `fix/*`, or `docs/*` for focused work. Use conventional commits:
`feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`, and `ci:`.

Before a pull request, read `AGENTS.md` and ownership docs, update tests and contracts with behavior,
run `npm run check`, and manually verify affected UI. Never commit secrets or real email. Gmail must
remain read-only and reply drafts must never be sent. Security reports follow `SECURITY.md`, not issues.
